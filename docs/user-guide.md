# User Guide

## Mentors
1. Sign up, complete your profile (expertise, industry, availability)
2. View suggested mentee matches, accept/decline
3. Set available time slots
4. After sessions, log attendance, notes, and follow-up actions

## Mentees
1. Sign up, complete your profile (goals, development needs)
2. View/accept a suggested mentor match
3. Book a session from your mentor's available slots
4. After sessions, leave feedback and check your dashboard progress

## Admins
Monitor matching, booking, attendance, and total mentoring hours on the admin dashboard.
